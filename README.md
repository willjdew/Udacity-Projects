# Udacity-Projects

Projects I completed in Udacity programs.

## Data Analysis Nanodegree

| Project | Description | Tools |
|---|---|---|
| [Titanic](Data%20Analysis%20Nanodegree/Titanic) | Explores which factors (passenger class, sex, title, age and others) affected a passenger's chance of surviving the Titanic sinking. | Python, pandas, Jupyter |
| [Open-World-Map](Data%20Analysis%20Nanodegree/Open-World-Map) | Wrangles OpenStreetMap data for Moab, Utah: parses and cleans the XML, converts it to JSON, loads it into SQLite and explores it with SQL queries. | Python, SQLite, SQL |
| [Red Wine Summarization in R](Data%20Analysis%20Nanodegree/red-wine-summarization-in-r) | Exploratory analysis of red wine chemical properties to find which factors relate to higher quality ratings. | R, ggplot2, R Markdown |
| [Enron-Identify-Fraud](Data%20Analysis%20Nanodegree/Enron-Identify-Fraud) | Builds a machine learning classifier on the Enron email and financial dataset to identify persons of interest in the Enron fraud case. | Python, scikit-learn, pandas |
| [Baseball-Data-Visualization](Data%20Analysis%20Nanodegree/Baseball-Data-Visualization) | Interactive chart of player weight versus home runs from a baseball dataset. | D3.js, dimple.js, Python |
